# Site alternance

Page perso (privée, non indexée) qui liste les alternances data / SQL trouvées par le bot `jobs-bot`.

- `index.html`, `style.css`, `app.js`, `bot.svg` : la page (style dans `theme.css`).
- `offres.js` : données, réécrites par le bot à chaque passage.
- `patch-jobs-bot.patch : ajout à appliquer dans une copie du bot `jobs-bot` pour générer `offres.js`.
